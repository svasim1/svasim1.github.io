A small project to implement a seed map (like [Chunkbase](https://www.chunkbase.com/apps/seed-map) or mcseedmap) as a mod in Minecraft. This [project](https://mcseedmap.net/) started off as a [school project](../School Projects) but I later decided to do it in my spare time, mainly to learn Java but also to make this mod happen.

The mod currently works, but is not optimized at all because I had issues with rendering in Fabric.

I've put the project aside, but I made it open source in hope of someone stumbling upon the project to continue the work.
