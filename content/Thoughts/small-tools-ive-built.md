Not every project needs to be big. Some of my favorites are small tools I built in a few days, either to fix an everyday annoyance or to try something I hadn't done before.

### Magneten Lunchmeny (2022)

[GitHub](https://github.com/svasim1/magneten-lunchmeny)

A Python script that fetches the week's lunch menu for [Magneten](https://www.magneten.nu/lunch) from the restaurant's API and prints today's dishes, refreshing on a schedule. 

This script was made during my time at Hitachigymnasiet, where I wanted to automatically fetch the daily lunch menu to display it on a screen for all students to see. However, since then a lot has probably changed and this script is most likely not working anymore.

### VoidIRC (2025)

[GitHub](https://github.com/svasim1/voidirc)

A web chat in the style of IRC, built with Koa and WebSockets. It has chat rooms, nicknames without duplicates, and classic commands like `/nick`, `/join`, `/msg` and `/list`. This was a quick school project and a fun idea, to make my own web chat.

### Circuit Planner (2026)

[GitHub](https://github.com/svasim1/circuit-planner)

A browser tool for planning electrical circuits, made to teach the basics of circuit design and layout. It's built with plain HTML, CSS and JavaScript, no framework needed. Also a school project to simulate circuits. I'm gonna be honest saying that this project did not turn out great and was never finished.

### Why small projects

I love small projects made to solve a specific problem. They're lightweight, quick to make and a lot of fun. 

Because they're small, I can try out a new language or library without the pressure of a big project, and actually finish what I start. Most of them taught me something I later used in bigger projects, whether it was working with an API, real-time WebSockets or just keeping things simple.
